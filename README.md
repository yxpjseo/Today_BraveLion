# 오늘의 당당사자

석관동성당 당당사자 중고등부 주일학교의 **말씀 카드 뽑기** 웹 서비스입니다.<br/>
우체통 옆의 당당사자가 꺼내 준 말씀 카드를 확인하고, 이미지로 저장하거나 친구에게 공유할 수 있어요.

## 주요 기능

- **말씀 카드 뽑기** — 50장의 말씀 카드 중 한 장을 랜덤으로 뽑습니다. 카드마다 말씀에 어울리는 사자 캐릭터가 함께 나옵니다.
- **말씀 카드 저장** — 뽑기 결과 화면의 말씀 카드 영역을 보이는 그대로 PNG 이미지로 저장합니다.
- **공유** — 카카오톡, 링크 복사, 휴대폰 기본 공유창으로 결과를 보낼 수 있습니다. 링크를 받은 친구도 같은 카드를 볼 수 있습니다.
- **주일학교 소개** — 당당사자 중고등부 주일학교 소개, 미사 시간·장소, 인스타그램 링크를 제공합니다.

## 화면 흐름

```
말씀 뽑기 ──→ 로딩 ──→ 뽑기 결과 ─┬→ 말씀 카드 저장
    │           ↑                ├→ 카카오톡 / 링크 복사 / 공유하기
    │           └── 다시 뽑기 ────┘
    └─→ 당당사자 소개
```

| 화면          | 경로           | 내용                                            |
| ------------- | -------------- | ----------------------------------------------- |
| 말씀 뽑기     | `/`            | 우체통과 당당사자, "말씀 카드 뽑기" 버튼        |
| 로딩          | `/` (오버레이) | 당당사자가 우체통에서 말씀 카드를 꺼내는 연출   |
| 뽑기 결과     | `/card/[id]`   | 말씀 카드, 저장·다시 뽑기 버튼, 공유 아이콘     |
| 당당사자 소개 | `/about`       | 주일학교 소개, 주제 성구, 미사·장소, 인스타그램 |

뽑은 결과는 URL(`/card/01` ~ `/card/50`)로 표현되므로, 링크만으로 언제든 같은 카드를 다시 볼 수 있습니다.

## 기술 스택

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **html-to-image** — 화면의 말씀 카드 영역을 이미지로 저장
- **Kakao JavaScript SDK**, Web Share API, Clipboard API — 공유
- **Vercel** — 배포

서버와 데이터베이스 없이 프론트엔드만으로 동작합니다.

## 프로젝트 구조

```
src/
├─ app/
│  ├─ page.tsx              # 말씀 뽑기
│  ├─ card/[id]/page.tsx    # 뽑기 결과
│  └─ about/page.tsx        # 당당사자 소개
├─ components/              # UI 컴포넌트
├─ data/cards.ts            # 말씀 카드 50장 (말씀 + 사자)
├─ lib/                     # 뽑기, 공유, 카드 이미지 저장
├─ hooks/
└─ types/
public/
├─ lions/                   # 사자 캐릭터 이미지
├─ images/                  # 화면용 이미지
└─ og/                      # 링크 미리보기 이미지
```
